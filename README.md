### What I've built

**[Face Intelligence System](https://github.com/Pranav8307/Face-Intelligence-System)** — Face detection, recognition, clustering and celebrity lookup. MTCNN + FaceNet embeddings + FAISS vector search. Hybrid architecture: FastAPI backend on Colab, Streamlit frontend local. Built because I wanted to understand how production face pipelines actually work end-to-end.

**[Document Intelligence System](https://github.com/Pranav8307/Document-Intelligence-System)** — RAG-based document Q&A API. Upload a PDF, ask questions, get answers grounded in the document. FastAPI + FAISS + SentenceTransformers with TTL caching and rate limiting. Includes a mock LLM mode so it runs without API keys.

**[Semantic Search Benchmark](https://github.com/Pranav8307/Semantic-Search-Benchmark)** — Side-by-side comparison of BM25, FAISS Flat, FAISS IVF, FAISS HNSW, Cosine Similarity, and Hybrid Search on real documents. Measures latency, accuracy, and Precision@K. Built to understand tradeoffs, not just pick a winner.
